================================================================================
                        TROUBLESHOOTING
================================================================================

Q: I see "Cannot reach API" error on frontend
A: Make sure backend is running on port 3000
   Check: curl http://localhost:3000/health (should return {"status":"ok"})

Q: Port 5173 is in use
A: Vite auto-switches to 5174, 5175, etc. Check console for actual port

Q: Database connection error
A: Restart backend: Press Ctrl+C, then npm run dev

Q: Changes not showing
A: Clear browser cache (Ctrl+Shift+Delete) and refresh page
